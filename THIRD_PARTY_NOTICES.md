FLY8 keeps required license and attribution notices for third-party components that are actually integrated.

## Shizuku API

Version: 13.1.5

Source: RikkaApps/Shizuku-API

The API project is released under the MIT license and its documented manifest integration is used by FLY8.

## Virtualization engine

The reference architecture uses VirtualApp-style virtualization. FLY8 will only integrate virtualization code after the applicable source and license terms are verified for the exact code version being used. No vendor-specific application code or branding is copied into FLY8.
