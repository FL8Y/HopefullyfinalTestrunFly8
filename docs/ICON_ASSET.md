# FLY8 icon asset

The launcher icon uses the user's supplied **Cyber Eye OS: Where Are You?** artwork from their library. The crop isolates the cyan cyber eye and excludes the surrounding pop-up dialogs and lettering. It is packaged as a separate FLY8-owned Android resource; no reference app icon or asset is copied.

Resources:
- `mipmap-nodpi/ic_launcher_foreground.png` — transparent adaptive foreground.
- `mipmap-anydpi-v26/ic_launcher.xml` — adaptive launcher icon.
- `mipmap-anydpi-v26/ic_launcher_round.xml` — adaptive round icon.

Background color: `#01132A`. Artwork remains centered in the adaptive safe region so launchers can apply their own icon mask without cutting off the iris.

Source file used during generation: library asset `Cyber Eye OS: Where Are You?.png`. The original full artwork remains outside this repository.
